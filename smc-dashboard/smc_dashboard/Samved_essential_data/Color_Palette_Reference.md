## Usage Guidelines

1. **Primary Actions**: Use `#1E88E5` or `#2563EB` for buttons, links, and primary CTAs
2. **Success States**: Use `#16A34A` (green-600) for success messages, active status
3. **Errors/Destructive**: Use `#DC2626` (red-600) for errors, delete actions
4. **Health Card Green**: Use `#16A34A` and `#4ADE80` for the distinctive green header divider
5. **Labels**: Use `#1E40AF` (blue-800) for field labels in health card
6. **Blood Group**: Always display in `#DC2626` (red) to indicate medical urgency

## OKLCH Color Space Notes

This project uses the OKLCH color space for better color accuracy and consistency:
- **L** = Lightness (0-1)
- **C** = Chroma (saturation, 0-0.4 typically)
- **H** = Hue (0-360 degrees)

Example: `oklch(0.52 0.191 242.5)` = Lightness 52%, Chroma 0.191, Hue 242.5° (blue)
